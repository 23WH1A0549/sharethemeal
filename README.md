# Share The Meal 🍱

A socially-driven web platform designed to reduce food wastage and help underprivileged communities by connecting food donors with people in need such as orphanages, homeless shelters, and NGOs.

---

# 📌 Project Overview

**Share The Meal** is a real-time food donation and distribution platform that enables users to donate surplus food and allows needy individuals or organizations to request meals based on location and availability.

The platform aims to:
- Reduce food wastage
- Support hunger relief initiatives
- Promote community engagement and social responsibility

# 📂 Modules

## 1. User Module
Handles registration, login, and profile management.

## 2. Donation Module
Allows donors to share food details including quantity, location, and contact info.

## 3. Request Module
Enables needy users and orphanages to request available meals.

## 4. Matching Module
Matches donors and recipients using location-based services.

## 5. Admin Module
Manages users, donations, and reports.

## 6. Notification Module
Provides real-time alerts and confirmations.

---

# 🧩 System Workflow

1. User registers/login  
2. Donor uploads food details  
3. Meal data stored in MySQL database  
4. Needy users browse available meals  
5. Users request or claim meals  
6. Notifications sent to donor and receiver

# ⚙️ Installation Steps

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/share-the-meal.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd share-the-meal
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Configure Environment Variables

Create a `.env` file and add:

```env
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=share_the_meal
JWT_SECRET=your_secret_key
```

## 5️⃣ Start the Server

```bash
npm start
```
